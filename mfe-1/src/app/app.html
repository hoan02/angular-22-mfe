Tech Stack

  • Framework: Angular {{ title() }}

Configuration Highlights

  • denseChunking — smaller remoteEntry.json metadata
  • cacheExternalArtifacts — cached shared libs (RxJS, etc.)
  • rebuildDelay — 500ms debounce for dev rebuilds
  • Shim Import Map — cross-browser compatibility
  • includeSecondaries: keepAll — all @angular/core entry points
